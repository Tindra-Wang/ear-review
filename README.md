# 听见 · 自然语言处理课程项目

源码位于 [`ear-review`](ear-review)，核心为中文耳机评论的方面情感分析、原文证据、产品画像与对比。

**使用方法：进入 `ear-review`，双击 `启动系统.bat`。** 启动器自动检查 Node.js、安装缺失依赖、构建并打开网页；首次准备需要网络。
