# Chinese-English Product Review Sentiment Dataset

This dataset contains 1,000 structured Chinese-English product reviews, each labeled with sentiment tags.

## 📦 Dataset Structure

| Field        | Description                                       |
|--------------|---------------------------------------------------|
| id           | Unique identifier (e.g., id_001, id_002, ...)     |
| category     | Product category (headphone, smartphone, tablet)  |
| zh_review    | Product review in Chinese                        |
| en_review    | Corresponding English translation (natural tone)  |
| sentiment    | Sentiment label (positive, neutral, negative)     |

## 🧠 Use Cases

- Sentiment analysis and classification
- Bilingual machine translation tasks
- Cross-lingual language modeling
- AI chatbots and customer support training
- Fine-tuning open-source LLMs

## 🔖 File Information

- Format: CSV (UTF-8 encoding), XLSX (adaptive column width)
- Sample size: 1,000 entries
- Real-world sentiment distribution (not manually balanced)
