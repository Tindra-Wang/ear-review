# 真实平台评论与浏览器自动采集

更新日期：2026-10-14。当前实际数据来源为具体京东商品评论；以下记录实际采集与实现，不将有限样本作为领域模型准确率证据。

## 1. 持久化Chrome浏览器自动采集（无需扩展/配对码）

用户要求取消扩展及配对流程，生产实现现为原生Google Chrome启动加Playwright的CDP连接。系统使用固定的data/runtime/chrome-collector-profile专用配置目录，而非每次新建临时浏览器上下文；从连接后的默认上下文读取页面，不再创建空登录态的新context。配置目录保留该采集浏览器的登录态，不复制或接管用户日常Chrome的配置文件。首次正常登录/验证和后续登录过期时需用户操作。

启动参数仅包含固定专用配置目录、本机调试端口、初次运行提示选项和商品URL；不采用隐藏自动化标志、代理轮换或验证码绕过。调试服务使用127.0.0.1和临时端口，不对公网开放。系统仅关闭自己启动的采集专用Chrome；不会关闭日常Chrome。数据目录与登录态不提交Git。

用户流程：填写商品URL及指定条数 → 点击打开Chrome辅助采集 → 系统自动启动、读取和连续加载 → 到达条数后保存CSV。遇登录/页面验证时正常完成，系统监测返回原商品页后自动继续，不需二次点击。系统尝试点击评价标签，等待评价区，提取可见评论节点并去重，寻找下一页或滚动新版评价弹窗加载，每次最多100条，加载次数上限按目标条数动态计算，最多100次，每页间隔1.5秒；达到条数上限、无新评论或找不到可用下一页时停止并生成实际已得CSV。可另用“读取当前评论页”配合手动翻页，最后结束生成CSV。只有实际评论节点会被读取，不把广告整页文本当评论。

## 2. 状态、接口与实测边界

POST /api/collections的method=browser打开采集Chrome；POST /api/collections/:id/read读取当前页；POST /api/collections/:id/auto在后台自动读取/翻页并将进度回写collections；POST /api/collections/:id/finish结束手动采集。全部写接口仍需本机管理员登录。已删除扩展目录、配对码入口与无管理员令牌的visible接收接口。

自动采集期间状态running，用户不能并发启动另一任务。首次无可读取评论或页面验证时回到waiting并显示原因，窗口保留，自动等待正常登录及返回原商品页，最多等待5分钟；超过时显示原因并保留数据，可重试。已读取评论不断保存，失败不丢已有CSV。20分钟到期或专用窗口关闭后已有结果保留，状态partial或blocked；后台重启未完成任务标失败，配置登录态仍在专用目录。CSV需用户核对并确认导入才进入正式评论和NLP分析。

用户正常浏览器能访问京东，旧自动化临时会话曾被拦截，具体平台规则未知。历史原生Edge实测曾正常打开商品https://item.jd.com/100239311413.html（华为FreeClip 2），采得3条真实评论，CSV为data/raw/jd-freeclip2-100239311413-real.csv，记录归档为实验结果/京东浏览器自动采集实测-Edge.json。用户随后要求改Chrome，当前生产固定使用Chrome CDP。Chrome任务7首次打开商品后跳转passport.jd.com正常登录页；用户完成登录后，同一会话实际读取完整评价弹窗并滚动加载，采集50条去重评论，任务completed、error=null。真实CSV为[data/raw/jd-freeclip2-chrome-100239311413-real.csv](../data/raw/jd-freeclip2-chrome-100239311413-real.csv)，实际任务记录见[京东浏览器自动采集实测.json](实验结果/京东浏览器自动采集实测.json)，行数、原文去重及SHA256见[京东真实CSV校验.json](实验结果/京东真实CSV校验.json)。采集CSV保存在collections表，可在平台采集页下载或预览并导入；采集实测只记录获取CSV；正式导入及模型分析状态以工作台当前批次/任务为准。平台当前排序的50条不是随机或全量样本，不能推断总体好评率，也不等同于本项目独立核验购买真实性。

## 3. 开发与复现

平台采集页生成CSV后，通过现有预览/导入接口保存评论并创建本地模型任务。生产采集仍使用Playwright，但通过CDP连接系统Chrome，未使用chromium.launch创建临时生产会话。无需Python或安装扩展。专用浏览器配置位于data/runtime/chrome-collector-profile；不要上传此目录或在其运行时删除目录。

核心测试在真实原生Chrome中连接CDP，验证可见DOM提取、去重、自动点击下一页、条数上限、拒绝其他商品，以及关闭重开后localStorage保存；页面为受控夹具，不是京东采集结果。接口测试验证自动进度/CSV写入及完成状态；端到端验证Web入口与导入衔接。

## 5. 只采到3条的定位与修复（2026-10-14）

历史任务8（华为）和9（小米）均要求50条、实际3条，停止原因是未找到下一页/滚动区；历史任务7采满50条。前两条并非0条失败，而是只取得商品详情页预览、未继续进入完整评价区。旧实现只检查首个“全部评价”匹配项是否可见，并忽略点击及弹窗等待异常；隐藏重复入口、入口延迟渲染、弹窗延迟都可能导致退回读取预览。未保留历史页面DOM，不能确定每次具体触发了哪一个分支。

当前实现仅选择可见入口，等待入口最多15秒、点击最多8秒、完整评价弹窗最多15秒；未成功打开时明确报错并保留窗口，不把3条预览当作完整自动采集。已打开弹窗时直接继续读取。达到条数上限则completed；提前因无新评论、无下一页/滚动容器或加载次数上限停止时partial，CSV继续可下载。界面显示“部分采集”和实际/设定数量，部分结果的停止原因用说明色，不冒充整次失败。历史同类3条记录只校正状态，不修改CSV或数量。

通过带隐藏重复入口、延迟显示按钮的Chrome夹具及状态/CSV保留测试。实站重新测试商品100239311413和100258708153，任务11与12均completed、50/50条、error=null；没有修改历史记录来冒充新成功。结果见[京东评价弹窗修复复测.json](实验结果/京东评价弹窗修复复测.json)，真实CSV分别为[华为复测CSV](../data/raw/jd-100239311413-retest-real.csv)与[小米复测CSV](../data/raw/jd-100258708153-retest-real.csv)。该采样不是全量或随机样本，其他商品或后续页面变化仍可能导致部分结果。
## 6. 打开即自动采集（2026-10-14）

POST /api/collections创建method=browser任务后，浏览器就绪即调用后台自动采集，不需要调用/read或/auto。浏览器任务的autoRunning字段区分“任务仍在自动等待”与“自动运行已因异常停止”；页面等待正常登录时不再显示需要再次点击的开始按钮。登录/验证由用户正常完成，服务每1.5秒仅检查本机浏览器页面地址，返回正确商品页后自动恢复，不在等待中反复访问平台。

针对指定数量1～100，按原文指纹去重，最后一批只保留到请求上限，避免超过指定数量。加载次数由目标条数动态计算，最多100次，不再固定最多10次；滚动加载重新触发并允许连续3次未出现新评论后才停止，避免一次短暂加载延迟就结束。平台无更多评论或不支持加载时仍保存实际数量并标partial，不伪造足额数据。

Chrome受控测试验证了登录页等待→正常返回商品页→同一调用自动恢复；接口测试创建后直接完成；端到端测试只点击一次并设置7条，无第二次开始或逐页读取调用。实站记录见[打开即自动采集实测.json](实验结果/打开即自动采集实测.json)，具体数量以记录为准。

本次实站只通过POST /collections创建浏览器任务并轮询，没有调用第二次/auto或逐页/read：华为任务14请求37条、实际37条；小米任务15请求100条、实际100条，均completed且error=null。CSV分别为[华为37条](../data/raw/jd-100239311413-automatic-37.csv)与[小米100条](../data/raw/jd-100258708153-automatic-100.csv)。正式页面截图：[37条](实验结果/打开即自动采集-37条.png)、[100条](实验结果/打开即自动采集-100条.png)。原有手动任务13的17条数据保留。本次是已有登录态的实站采集；登录后自动恢复另以受控Chrome测试验证，不宣称已独立重复真人登录实验。
