# 听见 · 耳机评论分析

TypeScript + Vue 3 + NestJS + SQLite。面向整批蓝牙耳机评论：上传CSV、调用本地模型、汇总正面与负面反馈、展示六方面分布并核对原文。

## 一键启动

双击 **`启动系统.bat`**：检查 Node.js，缺失或过旧时使用 Windows `winget` 安装 Node.js LTS；安装锁定的 npm 依赖，构建后打开网页。首次需要网络，系统安装可能出现管理员权限或安装器提示。没有 winget 时，启动器会提示从 [Node.js 官网](https://nodejs.org/en/download)安装。

仅安装/检查环境：双击 **`安装环境.bat`**，或在项目目录运行：

```powershell
.\安装环境.bat
```

已安装 Node.js 24.14 或更高版本时：

```powershell
npm run setup
npm start
```

`npm run setup` 检查依赖是否匹配锁文件，缺失时执行 `npm ci`，源码变化时重新构建；已准备好的环境不会每次重装。手动安装也可执行 `npm ci`、`npm run build`、`npm start`。

默认地址：http://127.0.0.1:3001 。启动窗口保留运行；Ctrl+C 停止。已运行时复用现有服务。若自动打开浏览器失败，复制地址访问；日志在 `data/runtime/launcher.log`。

账号为 `admin`，首次生成的密码在 `data/runtime/admin-password.txt`。配置模板为 `.env.example`，可复制为 `.env`；设置方法见开发指南。

## 用户操作

1. 在“评论导入”登录，添加具体耳机名称与编号。
2. 上传自己的CSV，核对列映射、耳机归属及来源，选择本地模型，预览后导入并开始分析。
3. 在“评价总览”查看正负反馈和六项分布，在“产品画像”核对原文或复核错误。首页不会自动调用模型分析单条示例；单条试用放在页脚。
4. 有商品链接时，在“平台采集”填写耳机名称和链接，点击“打开 Chrome 辅助采集”。首次在采集专用Chrome中正常登录/验证，再点击“开始自动采集”，系统读取并尝试翻页、生成CSV。无需扩展或配对码。也可手动翻页并“读取当前评论页”，最后结束生成CSV，核对后导入。专用Chrome登录状态会保留。无需事先创建耳机。匿名采集保留为备用尝试。

公开采集每次1～100条、最多10页、页间隔1秒；失败与部分结果如实保存。2026-10-13匿名探测：京东HTTP444、天猫返回非评论数据，均未取得评论。因此当前不能保证无需登录就能从任意商品获取数据；不会用教学样例伪装采集成功。当前是本地单用户账户，未实现公网多用户数据隔离。

## 已导入的真实评论

数据库已有“公开蓝牙耳机评论集合（型号未知）”：40条公开原始评论，非教学生成。来自SetFit中文Amazon数据，关键词及人工筛选，涉及不同型号，不能用作FreeClip专属评价或市场好评率。同一40条Qwen3分析：v2首轮23条成功、17条失败；v3为32条成功、8条失败；v4使用原文片段编号协议后40条全部成功、0失败。当前结果均为v4，历史任务仍可查看。输出可用率不等于情感准确率。

CSV：[真实蓝牙耳机评论40条](data/raw/bluetooth-reviews-real-40.csv)。来源、筛选、数据库与结果记录见[真实数据与浏览器辅助采集](docs/真实数据与浏览器辅助采集.md)。模型服务和Web运行时，npm run data:real可复用批次重跑本次脚本；重试会更新同版本结果。

## 复杂评论语义分析

推荐本地文本模型（Ollama + Qwen3），朴素贝叶斯/规则保留作基线对照。从 [Ollama 官网](https://ollama.com/download/windows)安装并启动后执行：

```powershell
ollama pull qwen3:4b
```

默认模型下载约2.5GB；推理还需额外内存，速度取决于设备。安装器自动准备 Node/npm，**不会自动下载 Ollama 或权重**。打开“评论导入”检查连接，就绪后刷新页面，单条和批次默认选择语义模型。`.env` 可设置 `OLLAMA_MODEL`、`OLLAMA_URL`，更改后重启后端。语义分析未连接会明确报错，不会静默降级为基线。

上传自己的 CSV：登录 → 选择文件/编码 → 核对列映射 → 指定产品/集合 → 填来源 → 预览 → 导入并分析 → 到画像核对原文。没有编号时自动生成；没有产品身份时先创建“耳机评论集合（型号未知）”。最多5000行、每条5000字、5MB；基线分析上限仍为1000字，不截断超限评论。

本机已准备便携 Ollama：`tools/ollama/ollama.exe`；权重位于 `D:\NLP\大作业\模型权重`，由 `.env` 的 `OLLAMA_MODELS` 指定。双击启动时会检查并启动本地模型服务；其他电脑需另行准备运行时和权重，GitHub 不包含这些大文件。

```powershell
npm run model:start              # 启动本机模型服务
npm run model:pull               # 下载或校验 qwen3:4b 权重
npm run experiment              # 重新运行固定 42 条四方法对照，覆盖实验结果
npm run experiment -- --resume   # 仅恢复尚未完成且版本一致的检查点
```

数据网站、JSONL 转 CSV 命令及训练区别，见 [NLP 原理与数据](docs/NLP原理与数据.md)。实际本地推理、分类器训练和固定合成检查集的结果见 [模型对照实验报告](docs/模型对照实验报告.md)，不将这些结果当作真实消费者数据上的泛化成绩。
